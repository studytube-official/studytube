# ManaCue marketing operating system

## Positioning

ManaCueは「AI学習アプリ」ではなく、YouTubeで勉強する受験生が、動画を見ただけで終わらせないための学習サービスとして訴求する。

約束:

> 見ただけを、解けるに。

説明:

> 共テ13教科の動画を探して整理し、自分の言葉で説明する。AIが理解できている点と補う点を返し、3日後・7日後の復習につなげる。

ブランドの役割:

- CUE MAP: 抜け落ちを見つけ、学び直すための教科コンテンツ
- ManaCue: 学んだ動画を整理し、説明し、復習して身につけるプロダクト
- 共通表現: `CUE MAPで学ぶ。ManaCueで身につける。`

AIティーチバックという用語だけで始めず、広告では `1文で説明 → AIが理解の穴を返す` と具体的に説明する。

## Primary audience

- 高2後半から高3の共通テスト受験生
- YouTubeを日常的に学習へ使う
- 保存した動画が散らかる、見返さない、理解したつもりになる悩みがある

## Funnel

```text
CUE MAPのShorts・長尺動画
  → YouTube/TikTokプロフィール
  → ManaCueで教科を選択
  → 動画を再生またはマイリストへ保存
  → 学びを自分の言葉で説明
  → AIティーチバックと復習カード生成
  → 3日後・7日後に復習
```

登録は中間指標。最初の主要コンバージョンは `first_teachback_completed` とする。

## Content allocation

抜け落ちチェック問題は既存のCUE MAP Shortsを使う。それ以外は次の比率で運用する。

- 40%: 受験生の失敗・悩み
- 30%: ManaCueを使った具体的な勉強手順
- 20%: 実画面による機能証明
- 10%: 開発背景、改善、利用者の声

完成度の高い包括紹介動画は固定投稿・プロフィール訪問者向けに使う。日々の配信は、実画面、自然な声、短い悩み起点を優先する。

## Paid promotion rule

初期はオーガニック投稿で検証する。広告費は、同期間の投稿の中で以下が上位の投稿にだけ使う。

- 冒頭離脱が少ない
- 保存・共有が多い
- プロフィール遷移が多い
- UTM経由でティーチバック完了を生んだ

勝った自然投稿をSpark Adsへ転用し、完全新作の広告を先に大量配信しない。

## Weekly review

毎週、投稿単位で次を確認する。

1. 再生数ではなくプロフィール遷移数
2. 流入元別の教科選択率
3. 動画再生またはマイリスト保存率
4. ティーチバック画面の開始率
5. ログイン要求後の完了率
6. 3日後の復習カード完了率

200セッションまでは絶対値で判断しすぎず、フックと導線の比較に使う。
